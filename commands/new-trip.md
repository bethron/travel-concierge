description: Start planning a new trip (leisure or business) with templates and a short interview
---
Start a new trip plan. Use the plan-trip skill: load the traveller profile if
one exists, offer the quick-start templates, run the short interview for the
gaps, create the trip workspace under travel/trips/, then proceed to flights,
stays and activities. If the user typed anything after the command (e.g.
"/new-trip Lisbon in September"), treat it as the opening answer.
